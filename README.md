# Req2Ticket

Aplicación web para planificar y hacer seguimiento del trabajo de equipos de producto e ingeniería.

Permitirá organizar una empresa en proyectos y gestionar los elementos de trabajo mediante funcionalidades, sprints y un tablero Kanban configurable. Cada elemento tendrá un panel de detalle con descripción, criterios de aceptación, enlaces, comentarios e historial de actividad.
